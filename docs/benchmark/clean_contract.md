# Clean Benchmark Contract

- Total: 250 tasks, authored as a reviewed pool before splitting.
- Split: 150 Dev / 100 held-out Test.
- Categories: single-source 40, parameter extraction 40, multi-step 50,
  DB+document 40, ambiguous/clarification 25, error recovery 30, no-tool 25.
- Public task data and private evaluator ground truth are separate.
- Success conditions are machine-checkable and permit valid alternative tool
  paths where appropriate.
- Split manifests and environment hashes are frozen before any Test use.
