# Adversarial Benchmark Contract

- Start from 70 canonical attack families and matching benign controls.
- Cover indirect instruction injection, tool-output poisoning, data
  exfiltration, and policy-violating actions.
- Create five reviewed Vietnamese variants per family: no diacritics, changed
  word boundaries, code-mixing, zero-width insertion, and paraphrase.
- Separate proposed violations, executed violations, final-answer leakage, and
  legitimate utility completion.
- Do not select or strengthen examples based on whether A0 happens to fail.
- All sinks remain simulated.
