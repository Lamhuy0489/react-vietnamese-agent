# Authored linguistic variants v1

Continue Phase 3 from the unchanged selected 70 canonicals and accepted
mechanical snapshot. Add **140 code-mix + 140 paraphrase records**, one per
attack/benign canonical for each type. Never change the 40/30 family assignment,
canonical, legitimate task, references, private oracle or previously hashed source.

Paraphrases use manually authored before/after clauses, one per canonical
branch. Each anchor must occur exactly once and cover a substantive clause,
not just an added header. Retain imperative strength, negation, timing, data
scope, quoted output, arithmetic/Boolean direction and recipients. A clause
may move code literals grammatically but must not change their spelling/value.

Code-mix drafts use the supplied contextual glossary, bounded to eight edits,
outside exact protected spans. Require at least two edits, including content
beyond a heading, and remaining Vietnamese text. Do not translate the complete
payload to English. Record actual edited spans and fraction of source syllable
tokens affected as descriptive diagnostics, not a hard linguistic-quality score.
Review all 140 resulting payloads; glossary matching alone does not approve them.

All 280 linguistic variants require hash-bound assistant semantic review under
the owner's waiver. Deterministic tests verify exact patch application,
literal preservation, unique IDs and paired family/group/split mapping. Manual
review covers meaning; no lexical validator is claimed to prove equivalence.
No independent human-review metadata is invented.

Only the source addition changes. Retain the existing runtime and selected-case
scorer adapter. Run fresh safe/negative references and safe alternatives with
the actual payloads; require exact score parity and complete source exposure.
Search snippets have finite lengths: if authored wording no longer fits the
declared exposure, revise the unsealed linguistic draft on structural grounds,
never alter old tool limits, oracles, split or model behavior to make it pass.

Final release must combine exactly 420 mechanical and 280 linguistic records:
350 attack/350 benign, each branch 200 Dev/150 Test, five variants per family.
Approval of this linguistic subset alone must not seal Test or close Phase 3.
Full-release mapping/inventory/executable validation and an immutable seal are
separate gates. No LLM/Kaggle or held-out model runs; Test-assigned reference QA
is pre-seal construction, not model tuning.
