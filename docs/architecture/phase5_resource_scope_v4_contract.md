# Host-bound public resource scope v4

Phase 5 development successor to frozen scope v3/runtime v8. Inputs are raw user
instruction and an immutable host SourceCatalog; no evaluator, oracle, model
outcome or attack-family identity enters policy. Old profiles/results stay intact.

Only exact AWB_/AUX_ document/page identities bound to the corresponding tool,
argument and source type can extend the legacy DOC/CDOC/CACHE namespace. A host
resource index is an inventory, not a grant. Extended resources require an
affirmative raw-user anchor; merely existing or being mentioned in a tool result
does not authorize a read. Ambiguous cross-type identities fail configuration.
Unknown identities, extra arguments, case changes and path/format characters do
not acquire aliases. Resource counts and user-input budgets remain bounded.

Preserve quoted/conditional/negative instruction rejection. The exact Vietnamese
phrase `cho biết` may occur in an affirmative read clause; `không`, `chớ`, `cho`
alone and other rejected forms still reject that clause. No broad normalization
or general Vietnamese language-understanding claim. Legacy table/column pairing
and unsupported SQL/search semantics remain unchanged; WHERE/row filtering is
explicitly still open, not silently permitted by namespace support.

The public Dev catalog builder mirrors the accepted overlay trust mapping and
exact trigger binding. Auxiliary documents/pages have known type/identity but
unknown sensitivity/trust: S2/UNTRUSTED, independently of referring-source labels.
Do not classify them by text, synthetic secret fields or oracle expectations.
Runtime v9 supplies the same task-local index to both scope decisions and host
source checks, without process-global patches. A0–A3 never enforce v4 scope.

Acceptance: deterministic index/anchor/negative/mutation controls; unchanged SQL
pair isolation; real Broker traversal with original public tool bytes at A0–A6;
unrequested source denied at A4–A6; task-local state and policy metadata; exact
Dev selection/source pins and matched catalog equality. These are CPU plumbing
checks, not native GPU execution or semantic utility/ASR/FPR. Full setup, Ruff,
mypy, pytest, knowledge links and source/data/raw receipt integrity must pass.

Only pinned Dev files may be read. No Test payload, private oracle, benchmark
rewrite, prompt/schema relaxation, model allocation, network tool effect or
new Kaggle submission in this bounded implementation milestone.
