# Ordinary A/B/A exact package v1

Phase 5 technical feasibility only. No benchmark policy, model identity,
decoding, held-out inputs or accepted historical source changes.

## Package and execution

Use the hash-bound guard Dataset v1, frozen bootstrap and 42-file efficient
stress overlay, extended by 14 ordinary request/metadata/audit source files.
The resulting 56-file overlay cannot overwrite base files. All selected bytes,
including wrapper and builder, must match the explicitly resolved Git commit.
Unrelated dirty plans/reports may coexist; they are not uploaded or reset.

The private, Internet-disabled script targets the same pinned Kaggle image,
Qwen7B mount and guard snapshot. Keep base-runtime identity separate from the
new wrapper/source identity. First run the frozen eight-tool/Dummy/resume checks.
Then collect authenticated tokenizer configs from actual model mounts, retain
pinned publisher sidecars, run ordinary A/B/A (three calls per role), and invoke
the full tokenizer/native artifact auditor. Publisher sidecars are package
copies; the joined auditor binds them to actual admitted model-file identities.
Any error stops execution without retries; raw partials remain unaccepted.

## Local acceptance

`scripts/prepare_phase5_ordinary_pair.py` requires the original local bundle and
pinned tqdm wheel. It hashes archives/wheels but does not extract model tensors.
For each archive/expanded-with-bound-PAX source layout it creates a fresh venv,
installs only verified offline base wheels, and uses the packaged `src` for
every subprocess. No inherited development-venv or working-directory imports.

Each layout must pass eight-tool schema/execution/recovery, all 21 selected
public Dev Dummy tasks, full resume, and a missing-one-task resume preserving
20 prior checkpoints. Run real spawned ordinary stub workers and independently
audit the six-call outputs twice. Collect public metadata only, then run the
complete joined audit twice against separately authenticated saved synthetic
fixtures. Those fixture paths and contents are never added to the GPU payload.
Retain CPU checkpoints and per-file hashes in a fresh build directory.

Mutation tests cover overlay inventory/hash/overwrite, selected Git bytes,
native command routing and fail-stop/no-retry behavior. Native command tests
mock execution explicitly; they are not model or native-library measurements.

## Remaining gates

Exact CPU preflight is not a GPU run, native tokenizer execution or remote
source authentication. After full QA and GitHub push, verify current quota,
private Dataset readiness/version and available image/model mounts before any
new submission. Use a new kernel identity; do not rerun old stress identities.
Downloaded native evidence still needs independent release-level source/remote
identity validation. Neither this package nor a six-call technical probe closes
Phase 5 runtime A0–A6, agent-only ownership, lifecycle or grouped Dev quality.
