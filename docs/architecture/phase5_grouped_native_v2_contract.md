# Grouped Dev native runner v2

Phase 5 Dev diagnostic only. Preserve v1 CPU evidence, runtime v10, public Dev
selection and all frozen policy/model/data bytes. No held-out payload or oracle.

Use the existing 112 variant+level keys and eight predetermined matched-pair
shards. Native Qwen agent/guard and generation remain pinned as in the accepted
loader evidence. A0/A1 are agent-only; A2–A6 use the sanitized native guard
observer outside attention/policy wrappers. A separate stub mode tests routing;
its outputs cannot authenticate native inference or measure utility/ASR/FPR.

Each task has fresh environment/workers and immutable outputs. Identity includes
source, public fixtures/catalog/configs, model inventory and content-bound guard
snapshot, recovery sample policy and backend. Collect baseline and six recovery
samples after cleanup, require stable totals and final three free-byte samples
within the fixed 256 MiB tolerance before the next task. Preserve unrecovered
checkpoint and stop; partial attempts are never silently retried or overwritten.
Audit every saved prefix before resume. Retain all semantic terminal failures.

Native artifact auditing must bind model metadata, request/PID/policy/attention
metrics and sanitized guard diagnostics to runtime attempts. Failed/partial
roles remain marked unassessed, not converted to authenticated success. Separate
startup, model generation/token throughput, runtime, cleanup and full task timing;
include failures in denominators. No hidden reasoning or raw guard text sidecar.

Acceptance: deterministic identity/resume/recovery negatives, real-spawn stub
coverage of all 112 keys, native factory routing controls, full setup/Ruff/mypy/
pytest/knowledge and independent source/raw/data hashes. Before any GPU dispatch,
also require exact archive/expanded offline package preflight, GitHub source,
private mounts and live quota checks. Native shard timeout is selected before
submission, never by observed semantic scores. CPU acceptance is not Phase 5
freeze or production guard quality. No change to Phase 6/7 scope.
