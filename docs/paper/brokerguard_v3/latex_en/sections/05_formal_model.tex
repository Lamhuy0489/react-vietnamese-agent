\section{Formal Model}\label{sec:formal}

This section states when the checks of Section~\ref{sec:method} suffice to prevent the harms of
Section~\ref{sec:threat}. Let $G$ be the tool and destination pairs that the user actually
authorises, $\Sigma$ the confidential values that the user does not allow to be disclosed, and $S$ the sinks with a
destination field. Grants are extracted once, before the first step. For each proposed call $a_t$, the gate
returns allow, deny or confirm, and confirm is enforced as a denial. Read calls are always allowed, and a call in $S$ is
allowed if and only if four conditions hold.
\begin{enumerate}[label=(G\arabic*), leftmargin=*]
\item The \rSig{} does not deny the call.
\item Condition~\eqref{eq:c1} holds for the call.
\item For some grant $g$ satisfying (G2), every pinned literal of $g$ occurs in $\data(a_t)$ and no Boolean is flipped.
\item Condition~\eqref{eq:c2} is false.
\end{enumerate}
Let $\hat G$ be the pairs that satisfy (G2). An allowed call is executed and its result $o_t$ gives $C_{t+1} = C_t \cup
L(o_t)$, where $L$ combines the \rFlow{} and \pTwo. The final answer is released after masking every value of $C_t
\setminus V$. Five assumptions delimit the propositions.
\begin{enumerate}[label=(A\arabic*), leftmargin=*]
\item \emph{Complete mediation.} Every tool call goes through the broker, and every tool with side effects is in $S$.
\item \emph{Sound extraction.} Every pair in $\hat G$ is in $G$. The converse affects only utility.
\item \emph{Label coverage.} Every value of $\Sigma$ appearing in a result $o_t$ is in $C_{t+1}$.
\item \emph{Transformation class.} If the agent leaks $v$ inside a string $w$, then $v \sub w$. Encodings, numbers
  written as words and values split across calls are excluded.
\item \emph{Complete pins.} For the grant $g$ authorising a call $a$, the pinned literals of $g$ include every value
  and Boolean the user stated for $a$.
\end{enumerate}
\begin{proposition}[Authorisation safety]\label{prop:auth}
Under (A1) and (A2), every executed sink call has its tool and destination pair in $G$. Hence no trajectory causes
redirection, and a read-only task causes no side effect.
\end{proposition}
\begin{proof}
By (A1), a sink $a$ is executed only if the gate allows it, so (G2) holds and the pair of $a$ lies in $\hat G$, which
is contained in $G$ by (A2). A read-only task has an empty $G$, so no sink is executed. \qed
\end{proof}

\begin{proposition}[Confidentiality]\label{prop:conf}
Under (A1), (A3) and (A4), no value of $\Sigma$ appears in $\data(a)$ of an executed sink call or in the released final
answer. Hence no trajectory causes leakage through the forms covered by (A4).
\end{proposition}
\begin{proof}
Suppose $v \in \Sigma$ appears in $\data(a)$ of a sink $a$ executed at step $t$. Since $v \notin V$, the agent can
only have obtained $v$ from an earlier result, so $v \in C_t$ by (A3). By (A4), $v \sub \data(a)$, so \eqref{eq:c2}
holds and (G4) fails, contradicting (A1). For the final answer, masking replaces every surface form matching $\kappa(v)$
before release, so by (A4) no form of $v$ remains. \qed
\end{proof}

\begin{proposition}[Integrity]\label{prop:int}
Under (A1), (A2) and (A5), every executed sink call contains every value the user stated for it and no Boolean opposite
to a stated one.
\end{proposition}
\begin{proof}
By (A1), a sink $a$ is executed only if (G2) and (G3) hold, so some grant $g$ authorises $a$, every pinned literal of $g$
occurs in $\data(a)$ and no Boolean is flipped. By (A2), $g$ is a grant the user actually made, and by (A5), its pinned
literals include every value the user stated for $a$. \qed
\end{proof}

\noindent The propositions give sufficient conditions under the assumptions, not unconditional guarantees.
Proposition~\ref{prop:int} does not exclude another value being added next to a pinned literal. Read calls and sinks
without a destination field lie outside $S$, so a read tool fetching a URL chosen by the model can still leak data.
