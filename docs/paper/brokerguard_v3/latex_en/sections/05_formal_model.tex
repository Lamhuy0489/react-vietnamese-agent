\section{Formal Model}\label{sec:formal}

The broker state after step $t$ is $s_t = (u, P(u), C_t, H_t)$, where $H_t$ is the history of executed calls and
observations, and $P(u)$ is built once before the first step. Let $R$ be the read tools and $S$ the sinks with a
destination field. Every proposed call $a_t$ goes through a gate $\mathrm{gate}(s_t, a_t) \in \{\mathsf{allow},
\mathsf{deny}, \mathsf{confirm}\}$, with $\mathsf{confirm}$ enforced as $\mathsf{deny}$. For $a_t \in R$ the gate always
allows. For $a_t \in S$ it allows if and only if (G1) the \rSig{} does not deny $a_t$, (G2) $a_t$ satisfies
\eqref{eq:c1}, (G3) for some grant $g$ satisfying (G2), every $p \in \mathrm{pins}(g)$ has $p \sub \data(a_t)$ and no
Boolean in $\data(a_t)$ is opposite to a pinned one, and (G4) \eqref{eq:c2} is false. Let $\hat G(u)$ be the (tool,
destination) pairs that satisfy (G2). An allowed call is executed, $(a_t, o_t)$ is appended to $H_t$, and $C_{t+1} =
C_t \cup L(o_t)$, where $L$ combines the \rFlow{} and \pTwo. A denied call yields an observation reporting the denial.
The final answer is released as $\mathrm{redact}(y, C_t \setminus V(u))$. Five assumptions delimit the propositions.
\begin{enumerate}[label=(A\arabic*), leftmargin=*]
\item \emph{Complete mediation.} Every tool call goes through the broker, and every tool with side effects is in $S$.
\item \emph{Sound extraction.} $\hat G(u) \subseteq G(u)$. The converse direction affects only utility.
\item \emph{Label coverage.} Every $v \in \Sigma$ that appears in an observation $o_t$ belongs to $C_{t+1}$.
\item \emph{Transformation class.} If the agent leaks $v$ inside a string $w$, then $v \sub w$. Encodings, numbers
  written as words and values split across calls fall outside this class.
\item \emph{Complete pins.} For the grant $g$ authorising a call $a$, $\mathrm{pins}(g)$ contains every value and Boolean
  the user stated for $a$.
\end{enumerate}

\begin{proposition}[Authorisation safety]\label{prop:auth}
Under (A1) and (A2), every executed sink call has its (tool, destination) pair in $G(u)$. Hence no trajectory satisfies
$H_\mathit{dest}$, and a read-only task never satisfies $H_\mathit{side}$.
\end{proposition}
\begin{proof}
By (A1), a sink $a$ is executed only if the gate allows it, so (G2) holds and $(\mathrm{tool}(a), \dest(a)) \in \hat
G(u) \subseteq G(u)$ by (A2). A read-only task has $G(u) = \emptyset$, so no sink is executed. \qed
\end{proof}

\begin{proposition}[Confidentiality]\label{prop:conf}
Under (A1), (A3) and (A4), no value of $\Sigma$ appears in $\data(a)$ of an executed sink call or in the released final
answer. Hence no trajectory satisfies $H_\mathit{leak}$ through the forms covered by (A4).
\end{proposition}
\begin{proof}
Suppose $v \in \Sigma$ appears in $\data(a)$ of a sink $a$ executed at step $t$. Since $v \notin V(u)$, the agent can
only have obtained $v$ from an earlier observation, so $v \in C_t$ by (A3). By (A4), $v \sub \data(a)$, so
\eqref{eq:c2} holds and (G4) fails, contradicting (A1). For the final answer, redaction replaces every surface form
matching $\kappa(v)$ before release, so by (A4) no form of $v$ remains. \qed
\end{proof}

\begin{proposition}[Integrity]\label{prop:int}
Under (A1), (A2) and (A5), every executed sink call contains every value the user stated for it, compared under
$\kappa$, and carries no Boolean opposite to one the user stated.
\end{proposition}
\begin{proof}
By (A1), a sink $a$ is executed only if (G2) and (G3) hold, so some grant $g$ authorises $a$, every literal of
$\mathrm{pins}(g)$ occurs in $\data(a)$ and no Boolean is flipped. By (A2), $g$ is a grant the user actually made, and
by (A5), $\mathrm{pins}(g)$ contains every value the user stated for $a$. \qed
\end{proof}

\noindent The propositions are sufficient conditions under the assumptions, not unconditional guarantees.
Proposition~\ref{prop:int} does not exclude another value being added next to a pinned literal. Read calls and sinks
without a destination field lie outside $S$, so a read tool fetching a URL chosen by the model can still become a
leakage channel. Table~\ref{tab:proven} distinguishes the properties that are proved from those that are only verified
empirically.
