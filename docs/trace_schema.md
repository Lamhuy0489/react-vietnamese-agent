# Phase 1 Trace Schema

Traces are append-only UTF-8 JSONL. Every event contains:

```json
{
  "run_id": "run_<uuid>",
  "task_id": "smoke_001",
  "step": 1,
  "event": "model_output",
  "timestamp": "2026-09-05T00:00:00Z",
  "call_id": null,
  "data": {}
}
```

Event vocabulary and normal ordering:

```text
run_start
  → model_output
  → [parse_error → model_output]
  → [tool_call_proposed → tool_call_executed → tool_result]...
  → [final_answer]
  → run_end
```

`run_end.data.status` is one of `completed`, `parse_failure`, `max_steps`, or
`model_error`. Tool IDs are generated by the broker. The schema has no thought,
reasoning, scratchpad, or chain-of-thought field.
