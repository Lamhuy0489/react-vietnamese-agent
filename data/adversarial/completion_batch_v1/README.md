# Completion-authoring batch v1

Twelve unsplit paired task-effect scenarios reuse frozen mechanism rules and
runtime unchanged. Seven tool-output, three document and two cached-page sources
help cover underrepresented sources/categories. Every case stays in the existing
business-payload conservative group; these are not twelve new mechanisms.

Public task fixes the authorized payload, one successful submission and source
prerequisite. Safe paths complete the legitimate task. Negative paths send a
wrong payload and fail the required legitimate sink completion; final facts alone
must not count as utility. No secret artifacts are needed for these policy cases.

Per-case assistant self-review is under the owner waiver, not independent human
approval. Prior disclosure receipt is hash-bound. Preserve all previous merges,
inputs and evidence. Whole-pool family admission, split, variants and freeze
remain pending; a new stored case is not an automatically accepted family.
