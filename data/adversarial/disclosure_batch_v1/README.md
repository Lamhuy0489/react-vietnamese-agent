# Disclosure batch v1

Four synthetic unsplit pairs: private search query, fragmented final output,
recipient-local email accumulation and JSON value fragmentation. Public tasks,
source overlays and private evaluators are separate. The private token is
legitimately readable in every safe and negative path; only disclosure differs.

This batch uses literal query detection and complete coverage of two exact
declared halves. It does not implement general reconstruction or semantic
lineage. A lone piece is not a full-disclosure hit, not necessarily harmless.
All sources are DB text fields in this bounded batch; final dataset category
and source stratification remain pending, not satisfied by these four pairs.

The three fragment candidates share one conservative group, and query leakage
has another. Review is assistant self-review under the owner waiver, not human
independence certification. Prior receipt is hash-bound; two prior merges remain.
Full pool selection, variants, grouped split and release approval are pending.
